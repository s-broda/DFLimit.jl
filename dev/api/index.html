API reference

The exported functions, by topic, and the parts of the engines that the guide names. The functions of the engines that are not exported are reached through their modules (DFLimit.DFExact, DFLimit.DFDet, DFLimit.DFKan) and described by the comments of their files.

The t-ratio

DFLimit.DFExact.ltratio_cdf — Function
ltratio_cdf(x, cas, c = 0; c0 = 0, g0 = 0, method = :auto, verified = false)

The limit as n -> inf of P[t <= x] for the least squares t-ratio t of the hypothesis phi = 1 + c0/n under phi = 1 + c/n, case cas ("DK", "DU", "DT": fixed start g0, default 0; "SK", "SU", "ST": stationary start, c <= -1e-4 (CSTAT); "DG": the GLS-detrended trend case of Elliott, Rothenberg and Stock, cbar = -13.5, zero start, line integral only). x may be an array. Non-finite x: 0 at -Inf, 1 at Inf, NaN at NaN. method: :auto (the fastest representation that one evaluation gives to well below 1e-5 at each point, see automethod), :single (the line integral representation; with a fixed start the noncentral kernel, a triple integral in cases DU, DT), :double (the conditional integral representation) or :contour (the contour integral representation, tr_contour: the inversion formula on paths around the singularities of the moment generating function, with the integral over v in closed form and the paths in s and t deformed, a double integral with an explicit integrand, for a fixed start g0 != 0 in cases DU, DT only).

verified = false (the default): one evaluation by one method at each point, no second evaluation, no refinement driven by an estimate, no fallback and no recomputation; a warning, once per call, where the parameters lie in a regime in which one evaluation is known to be brittle (brittle_msg). verified = true: the conditional integral with the agreement of two paths and the refinement of their rules, the contour integral as two structurally different evaluations refined until they agree, error estimates and a status (their flagged values come with a warning with :double and :contour), and with :auto the rule of automethod_verified, the flagged values given another representation's and the values below 1e-3 recomputed by the conditional integral, at 1 to 4 times the cost of the default (about 1.8 with the contour integral; more in the tails below 1e-3, which it recomputes). Further keywords go to the engine (tau, hu, N, pfac, ...).

Where the paths of the line integral would exceed the bounds of the engine (c0 < 0 near zero with x > 0, where a root of the parabola X(v) lies far out, and large x above the unit root; see path_error), it refuses the point before evaluating it: method = :auto then takes the conditional integral there (route_double), method = :single raises an ArgumentError that names the arguments (also case DG, which has the line integral only).

Two extensions of the limit, computed by the general engine (DFLimit.DFDet.dist_cdf; engine = :classical refuses them): vol = volpath(breaks, omega), the innovation standard deviation piecewise constant between known dates, and with c a vector of one value per regime the local-to-unity parameter as well (zero start, every c <= 0; method :auto or :paths); rho (default 1), the limit rho tau{c0} + sqrt(1 - rho^2) Z with Z standard normal and independent, which is the limit of the covariate-augmented t-ratio of Hansen (1995) at c0 = `cadfc0(c, rho, R)and of the t-ratio of the slope in a predictive regression with a regressor local to unity at c0 =predictive_c0(c, rho, b)` (rho in [-1, 1]; method :auto, :lines or :mixture).

ltratio_cdf(-2.86, "DU")                        # P[tau_mu <= -2.86] at the unit root
ltratio_cdf(-1.94087, "DK", -5)                 # power of the 5% test of tau at c = -5
ltratio_cdf(-3.41, "ST", -10)                   # trend case, stationary start
ltratio_cdf(0, "DK", 2; c0 = 2)                 # t-ratio centered at the true value

DFLimit.DFExact.ltratio_mom — Function
ltratio_mom(p, cas, c = 0; c0 = 0, g0 = 0, method = :auto, engine = :auto, verified = false, tol = 1e-10, err = false) -> m

m[j] = E[t^j], j = 1..p, for the limit (U - c0 V)/sqrt(V) of the t-ratio under phi = 1 + c/n (the moments of the limit in the Supplementary Material): E t^j = Gamma(j/2)^{-1} int0^inf s^{j/2-1} mj(s) ds, m_j(s) the j-th derivative of the moment generating function along its affine path.

By default (method = :auto with engine = :auto, where it is checked; see the README) the derivative comes from one Taylor-mode jet of order j at each node of an adaptive quadrature in log s, the method of Bao and Kan ("Exact Finite-Sample Distribution and Moments of the Least Squares Estimator in First-Order Autoregressions: O(1) Algorithms"; DFLimit.DFKan.tratio_mom1), with the closed-form transform of the six cases (any c0 and fixed start), 0.3 to 1.3 ms for four moments; tol is the relative tolerance of its quadrature, err = true returns (m, errors), and a warning names the moments whose error estimate exceeds tol times their size. method = :jets forces it, method = :engine is the computation of before (the derivatives as Cauchy integrals on a circle, by the classical engine, moments, or the general engine, by the rule of autoengine), which reproduces those values; engine = :classical or :general and further options take that computation too. verified = true recomputes the moments by the engines where an error estimate exceeds the tolerance.

ltratio_mom(4, "DU")[2]                         # 3.0559953450 (Nabeya, 1999)

The coefficient statistic

DFLimit.DFExact.coef_cdf — Function
coef_cdf(y, cas, c = 0; c0 = 0, g0 = 0, method = :auto, engine = :auto, verified = false, tol = 1e-12, err = false, opts...) -> F

The limit as n -> inf of P[n(phi^ - phi0) <= y] (y a number or an array) for the least squares estimate phi^ of phi in the regression of ltratio_cdf, under phi = 1 + c/n, with phi0 = 1 + c0/n (c0 = 0: the coefficient test of Dickey and Fuller, rho^ = n(phi^ - 1)). The limit is (U - c0 V)/V, so that P[(U - c0 V)/V <= y] = P[U - (c0 + y)V <= 0].

In the cases DK, DU, DT (zero or fixed start g0) and SK, SU, ST the default (method = :auto with engine = :auto) is the single inversion of the joint characteristic function along the ray of the half-plane, the method of Bao and Kan ("Exact Finite-Sample Distribution and Moments of the Least Squares Estimator in First-Order Autoregressions: O(1) Algorithms"): adaptive quadrature over decades, the tail completed by integration by parts with the derivatives from jets, the closed-form transform with the branch fixed at each point (DFLimit.DFKan), one evaluation of 0.02 to 1.5 ms a value with an error estimate, up to c = 20 (DFKan.INV_CMAX); tol is its absolute tolerance, and a warning, once per call, names the points at which the estimate exceeds it. err = true returns the error estimates as well, (F, errors) (NaN for values the single inversion did not compute). method = :inversion forces the single inversion (also above c = 20). method = :engine is the computation of before, the distribution function of the t-ratio at 0 with the local null value c0 + y, ltratiocdf(0, cas, c; c0 = c0 + y, g0, engine), with its choice of engine and representation (it reproduces the values of 0.5.0 and of the merged package before the single inversion); the t-ratio's representations (:single or :line, :double or :conditional, :contour), engine = :classical or :general, its further options and case DG take that computation too. verified = true keeps each value of the single inversion whose error estimate meets tol and recomputes the others by the checked computation of the engines (`ltratiocdf` with verified = true); with method = :engine it is that checked computation. As COEF_CDF of the MATLAB programs.

coef_cdf(-14.094, "DU", 0)                      # 0.05: the 5% critical value of rho^_mu

DFLimit.DFExact.adfmax_cdf — Function
adfmax_cdf(x, cas, c = 0; opts...) -> F

The limit as n -> inf of P[ADFmax <= x] under phi = 1 + c/n, no drift, for the larger of the Dickey-Fuller t-ratios of the forward regression (yt on y{t-1}) and of the reverse regression (yt on y{t+1}) of Leybourne (1995), with a constant ("DU", "SU") or a constant and a trend ("DT", "ST"), zero start ("D") or stationary start ("S", c <= -1e-4). Accurate to about 1e-11. As ADFMAX_CDF of the MATLAB programs (which also returns the error estimates).

Regions, linear forms and the power envelope

DFLimit.DFExact.ltratio_region — Function
ltratio_region(bnd, cas = "DK", c = 0; opts...) -> P

The limiting probability P{U <= g(V)} of a region of the plane under phi = 1 + c/n, no drift, zero start, case "DK" (no deterministic terms; also the constant case with GLS demeaning), with U = int J dJ and V = int J^2 as in ltratio_cdf. Every test of the unit root in the limit experiment of case DK rejects on such a region (the companion paper's section on the weighted-average-power test), and the first part of the conditional integral representation, the probability of a region of the plane, gives its probability for every boundary g, by one outer integral over V (tr_region). bnd is a NamedTuple (or a Dict) with the field type and its parameters:

  • (type = "line", a, b): g(v) = b + a v (the point-optimal test, U - aV <= b)
  • (type = "parabola", x, c0 = 0): g(v) = x sqrt(v) + c0 v (the t-ratio: P = ltratio_cdf(x, "DK", c; c0))
  • (type = "wap", k, omega): the weighted-average-power test with the half-normal weight of scale omega on c < 0, (1 + omega^2 V)^(-1/2) erfcx(U/sqrt(2 (V + 1/omega^2))) >= k
  • (type = "fun", g): g a function of one argument (a scalar v; in MATLAB g is elementwise in a vector v)

and optionally v0 (g = +Inf on (0, v0), whose probability P(V < v0) is added) and brks (kinks of g, as breakpoints of the outer rule). Options as in tr_region. Accurate to about 1e-11. As LTRATIO_REGION of the MATLAB programs, whose bnd is a structure with the same fields.

ltratio_region((type = "wap", k = 3.6658, omega = 10), "DK", 0)   # 0.05 (the weighted-average-power test of the companion paper)
source
DFLimit.DFExact.ltratio_lincdf — Function
ltratio_lincdf(b, a, cas, c = 0; cbar = -13.5, N = 60000, umax = 4000) -> P

The limit of P(U - aV <= b) under phi = 1 + c/n (b a number or an array), zero start, no drift, with U = int J dJ and V = int J^2 as in ltratio_cdf: case "DK" (no deterministic terms, and the constant case with GLS demeaning, whose limit is the same) or "DG" (the GLS-detrended trend case of Elliott, Rothenberg and Stock, detrended at cbar). The point-optimal test of Elliott, Rothenberg and Stock against cbar < 0 rejects for U - aV < b: in case DK with a = cbar/2 (its log likelihood ratio is cbar U - cbar^2 V/2), in case DG, with the data detrended at cbar, with a = cbar^2/(2 (cbar - 1)) (it rejects for small cbar^2 V + (1 - cbar) J(1)^2, J(1)^2 = 2U + 1); see power_envelope. a = NaN gives P(V <= b) (case DK).

In case DK the default (method = :auto with engine = :auto, a finite) is the single inversion of the joint characteristic function along the ray of the half-plane, the method of Bao and Kan ("Exact Finite-Sample Distribution and Moments of the Least Squares Estimator in First-Order Autoregressions: O(1) Algorithms"; DFLimit.DFKan), with the tail beyond S = 400/|w| (w = 1/2 + b) completed by integration by parts, where it is checked (see the README); tol is its absolute tolerance, err = true returns (P, errors), and a warning names the points at which the error estimate exceeds the tolerance. method = :inversion forces it, method = :engine is the computation of before (it reproduces those values): by the inversion formula of Gil-Pelaez (tr_gilpelaez) where its transform has decayed by the end of its grid and c <= 0, to about 1e-10; otherwise (|a| below about 0.3 to 3, depending on c, which includes a = 0, the law of U alone, and c > 0) by a conditional integral: in case DK that of the region {U <= aV + b} (ltratio_region), in case DG the conditional integral given U (lincond), to about 1e-10 and in [0, 1]; or the general engine, by the rule of autoengine. Case DG, a = NaN, the keywords cbar, N, umax and engine = :classical or :general take that computation. verified = true recomputes the values whose error estimate exceeds the tolerance by the engines' computation. c must be at least -550; in case DG at most about 3.5, and for a = NaN about 7 (an ArgumentError beyond). As LTRATIO_LINCDF of the MATLAB programs.

ltratio_lincdf(-0.2639, -3.5, "DK", 0)          # 0.05: the size of the point-optimal test at cbar = -7

DFLimit.DFExact.power_envelope — Function
power_envelope(c, cas = "DK"; alpha = 0.05, N = 60000, umax = 4000) -> P

The asymptotic power envelope of Elliott, Rothenberg and Stock (1996): the power at c (a number or an array) of the point-optimal level-alpha test against c itself, zero start, no drift: case "DK" (no deterministic terms; also the constant case, "DU", where the point-optimal test uses the GLS-demeaned data and the envelope is the same curve) and case "DG" (the trend case, the point-optimal test against c with the data GLS-detrended at c). The test against cbar rejects for small U - aV (ltratio_lincdf), a = cbar/2 in case DK and a = cbar^2/(2 (cbar - 1)) in case DG (where the limit of the invariant statistic of Elliott, Rothenberg and Stock is cbar^2 V + (1 - cbar) J(1)^2, J(1)^2 = 2U + 1): its critical value is the alpha-quantile at c = 0 and the envelope its power at cbar = c; alpha for c >= 0.

In case DK (and DU) the default (method = :auto with engine = :auto) computes both by the single inversion of the joint characteristic function along the ray of the half-plane, the method of Bao and Kan ("Exact Finite-Sample Distribution and Moments of the Least Squares Estimator in First-Order Autoregressions: O(1) Algorithms"; DFLimit.DFKan), the critical value by regula falsi to 1e-12, where it is checked (see the README); tol is the tolerance of each inversion, err = true returns (P, errors) (the sum of the two inversions' error estimates), and a warning names the points at which that exceeds the tolerance. method = :inversion forces it, method = :engine is the computation of before (the critical value by ltratio_bisect on [-50, 50] to 1e-9 on the inversion of Gil-Pelaez on a grid, or the general engine, by the rule of autoengine; to about 1e-10), which reproduces those values; case DG, the keywords N, umax and engine = :classical or :general take that computation. verified = true recomputes the values whose error estimate exceeds the tolerance by the engines' computation. As POWER_ENVELOPE of the MATLAB programs.

power_envelope(-7, "DK")                        # 0.4994: at cbar = -7 the envelope has power one half

DFLimit.DFDet.Determ — Type
Determ(br, C, name)

Piecewise polynomial regressors on [0, 1]: br the piece boundaries 0 = br[1] < ... < br[end] = 1, C[j] the (deg+1) x K matrix of the coefficients of r^k (k = 0..deg, in the global variable r) of the K regressors on piece j. A regressor is left-continuous at a break: piece j covers br[j] < r <= br[j+1] (r = 0 belongs to piece 1), so that a level-shift dummy 1{r > lambda} is 0 at r = lambda, as 1{t > TB} in the regression. Determ(br, C, name, true): the coefficients are those of the local variable r - br[j] on piece j (the form fdesign builds, well conditioned at high degree on short pieces). The last field is the statistic: :onestep, the t-ratio of y{t-1} in the regression of yt on d(t/n) and y{t-1} (the default), or :first, the statistic that detrends first (detrend_first).

DFLimit.DFDet.fdesign — Function
fdesign(f, breaks; K, name, tol = 1e-14, maxdeg = 96, sub = nothing) -> Determ

Deterministic terms given by a function: f(r) returns the vector of the K regressors at r, smooth on each piece between the breaks (0 < breaks < 1; jumps and kinks only there; left-continuous at a break, as in Determ). On each piece every regressor is replaced by its Chebyshev interpolant (first kind) of the smallest degree 2^m - 1 >= 15 at which the coefficients beyond the last that exceeds tol times the largest have fallen below it (an error beyond maxdeg). For the covariance the transfer-function formula needs Taylor coefficients, whose sum over the whole piece is ill conditioned at high degree (the monomials of sin(4 pi r) on [0, 1] reach 3e4); the piece is therefore cut into sub computational sub-pieces (default ceil(deg/4)) and the interpolant is re-expanded about the left end of each (cheb_taylor), where the terms g^(k) h^k / k! stay of order one. The design carries these local coefficients (Determ(..., true)).

DFLimit.DFDet.design_from_matrix — Function
design_from_matrix(X; breaks = nothing, name, tol = 1e-8, maxdeg = 40, minlen = 10) -> Determ

The design of the limit from the n x K matrix X of the deterministic regressors used in a regression (column k sampled at t = 1..n, any scaling). The known breaks, if given, are the indices TB after which the regressors change (a regime of t <= TB and one of t > TB, as 1{t > TB}), at lambda = T_B/n. Without them the breaks are detected: on each column scaled to unit maximum the sixth differences of a function smooth on the scale of the sample are of order n^{-6}, while a jump or a kink at T leaves a cluster of differences of order one or 1/n around T; each cluster gives the largest T (after which the regime changes) at which polynomials of degree at most 8 fit 30 observations on either side exactly (for a kink of a continuous regressor both T - 1 and T fit; T is the correct one). On each piece every column is then fitted by least squares in Chebyshev polynomials of increasing degree up to maxdeg until the largest residual is below tol (exact for polynomial and dummy columns, a smooth interpolant for others), and the design is the function design of these fits (fdesign). Columns that are not piecewise smooth at the sample's resolution (a piece shorter than minlen observations, as a pulse dummy makes, or no fit within maxdeg, as seasonal dummies give) are refused with an error: they do not affect the limit and should be left out. Columns linearly dependent on the others are dropped.

DFLimit — Module
DFLimit

The exact limiting distribution of the Dickey-Fuller t-ratio: the distribution function, density, quantiles and moments of the limits of the Dickey-Fuller t-ratios under local alternatives, by the exact representations of Bao, Broda and Kan, "The Exact Limiting Distribution of the Dickey-Fuller t-Ratio with General Deterministic Terms" (the lead paper, SSRN 7745921), and, for the classical cases, of its companion paper, "Low-Rank Representations of the Classical Dickey-Fuller Limits, with an Extension to Predictive Regressions" (SSRN 7725619).

The classical engine, that of the companion paper, is the module DFLimit.DFExact (the file src/DFExact.jl, with src/df_series.jl); DFLimit re-exports its exported functions (ltratio_cdf, ltratio_pdf, ltratio_icdf, ltratio_mom, adfmax_cdf, adfmax_pdf, adfmax_icdf, coef_cdf, coef_icdf, ltratio_region, ltratio_lincdf, power_envelope, ltratio_bisect), and the functions it does not export are reached as DFLimit.DFExact.cdf and so on. The engine is multithreaded: start Julia with -t auto.

The general engine, that of the lead paper (any piecewise smooth deterministic terms), is the module DFLimit.DFDet (the file src/DFDet.jl); the classical functions take its designs (trend, perron, fdesign, ...) in place of the case, and DFLimit.autoengine chooses the engine of every call (src/merged.jl; the README, "Two engines").

Three extensions of the limit, computed by the general engine: volatility and persistence regimes (volpath and the keyword vol of the t-ratio functions), a normal component (the keyword rho: the covariate-augmented t-ratio, the predictive regression; cadf_c0, predictive_c0) and the first t-ratio of seasonal unit roots at a harmonic frequency (hegy_t3_cdf, hegy_t3_pdf, hegy_t3_quantile).

DFLimit.DFExact — Module
DFExact

Exact density and distribution function of the limiting Dickey–Fuller t-ratio tau = U/sqrt(V), Models M1–M3 with local-to-unity parameter c (zero initial value and drift), by the line integral representation of the companion paper (the inversion formula with the s-integral done analytically): a port of df_exact2.py.

cdf(q, model; c = 0.0, start = :zero)       # P(tau <= q)

moments(model; c = 0.0, start = :zero, pmax = 4)   # raw moments, one-dimensional integrals
tstar(model, c)                             # the convergence abscissa in t

The line Re t = tau of the outer integral defaults to 1 for c <= 0 (where the abscissa t* exceeds 1 in all three models) and to t/2 for c > 0, where t_ decreases to zero as c grows; tau can be given explicitly.

For f = 0 the determinant D(s,t) is a polynomial in s of degree one (M1) or two (M2, M3) with coefficients depending on t alone, so that the inverse two-sided Laplace transform in s is explicit (a scaled chi-square(1) density for M1, the density of a difference of two scaled chi-square(1) variables, a Bessel K_0, for M2 and M3). The t-loops run on NWORKERS[] tasks (start Julia with -t 6 or more; -t auto gives only the performance cores on macOS): by default the smaller of the number of threads and the number of cores (on macOS the performance and the efficiency cores, whose help the dynamic schedule of the loops uses; elsewhere the physical cores, since using every hardware thread of a machine with hyperthreading makes it slower); set DFExact.NWORKERS[] to override.

DFLimit.DFDet — Module
DFDet

A research prototype: the exact limiting distribution of the Dickey-Fuller t-ratio for arbitrary piecewise polynomial deterministic regressors (polynomial trends of any order, level and slope breaks at known dates), by the inversion formula on paths around the singularities of the joint moment generating function (the contour integral representation of Bao, Broda and Kan), generalized from a determinant of degree at most two in s to any degree.

The model. J is the Ornstein-Uhlenbeck process dJ = c J dr + dW on [0,1], J(0) = 0. The regressors d(r) in R^K are piecewise polynomial with break points 0 < lambda1 < ... < lambdaq < 1, G = int d d', m = int d J, and

V = int J^2 - m' G^{-1} m,   U = (J(1)^2 - 1)/2 - m' G^{-1} w,   w = int d dJ = d(1) J(1) - int d' J - sum_i Delta_i J(lambda_i),

with Deltai the jump of d at lambdai. The Gaussian vector ell = (J(1), J(lambda_i) at the jumps, z) with z = int g J for an L2-orthonormal basis g of span{d, d'} makes U + 1/2 = ell' A ell and V = int J^2 + ell' B ell; the basis removes the linear dependences between m and n = int d' J, so that the covariance Sigma of ell is nonsingular and the rank r of A is the number of roots in s. Girsanov's theorem with theta = sqrt(c^2 - 2t), gamma = (c + theta)/2 gives

M(s,t) = E exp(sU + tV) = e^{-s/2} e^{-gamma} det(I - 2 (s A + t B + gamma E11) Sigma(theta))^{-1/2},

Sigma(theta) the covariance of ell under the Ornstein-Uhlenbeck law with parameter -theta started at zero. The function computes Sigma as int0^1 F(u) F(u)' du with F the transfer functions of the functionals (ellk = int0^1 Fk(u) dW(u)), which are in closed form on each piece in the functions ek(z) = int0^1 x^k e^{-zx} dx (series or a stable recurrence, no cancellation for small theta), and the integral over u by Gauss-Legendre panels graded toward the right end of each piece (the boundary layer e^{-theta (b - u)}).

DFLimit.DFKan — Module
DFKan

The numerical devices of Yong Bao and Raymond Kan, from their paper "Exact Finite-Sample Distribution and Moments of the Least Squares Estimator in First-Order Autoregressions: O(1) Algorithms" and its MATLAB programs, for the limits of this package. The method of every function here is theirs; the code is a port to the limit pair (U, V) of the package:

  • the joint characteristic function of the limit pair in closed forms that are free of cancellation on both sides of the unit root, with the branch of the square root settled at each point from factors whose arguments are known (no tracking along a grid), evaluated in Taylor-mode arithmetic (Jet), so that derivatives of any order come out of the same assembly (logcf);
  • the single inversion for statistics that reject on a half-plane (the coefficient statistic, the linear form U - aV, the power envelope): adaptive quadrature over decades and the tail completed by repeated integration by parts, the derivatives read off a jet (half_cdf, ratio_cdf, ratio_pdf, ratio_icdf, ratio_mom), each value with an error estimate; the package's coef_cdf, coef_pdf, coef_icdf, coef_mom, ltratio_lincdf, power_envelope and ltratio_mom take these for the six classical cases (src/merged.jl, the functions coef_cdf1 and so on here);
  • the branch of P(t), M0(t) and the labels of the roots of the classical line integral and contour integral at a single point t (`DFExact.tpartspoint, in the classical engine's file), and of the general engine's determinant from the pivots of the precision matrix (DFDet.DetCF, the file DFKan_det.jl, evaluated in the module DFDet: the point-optimal statistic andcoefcdfgp` by the single inversion, and the argument of log P(t) in the provider of the general engine's line integral);
  • the moments of the t-ratio at a local null value from one jet per node (tratio_mom1), and the distribution function of the t-ratio at zero in closed form (ray_cdf).

The pair is (U, V) of the package: the t-ratio is (U - c0 V)/sqrt(V) and the coefficient statistic (U - c0 V)/V. Bao and Kan write A = U - cV and B = V, so that E exp(i t1 A + i t2 B) = M(i t1, i (t2 - c t1)), M the joint moment generating function of (U, V). The case codes are those of the package; the start g0 of the package corresponds to their parameter by par = g0 (case DK), c g0 (case DU) and c^2 g0 (case DT).

Model

A design with a start for the Ornstein-Uhlenbeck process: :zero (J(0) = 0), :fixed (J(0) = g0) or :stationary (J(0) ~ N(0, -1/(2c)) independent of W, c < 0). With J(0) = x the functionals gain two terms,

U + 1/2 = ell' A ell - x^2/2 + x b' ell,   b = Pm d(0) on the z block,

DFLimit.DFDet.XSpec — Type
XSpec(c0, q, A; vmax = Inf, w = 1, dc0 = 0, dq = 0, dA = 0, bnd = true)

One term w P(R <= X(sqrt V), sqrt V <= vmax) of an event, with R = U + a (a the shift of Mt = e^{a s} M, Model) and the parabola X(v) = c0 v^2 + q v + A; (dc0, dq, dA) are the derivatives of its coefficients in the parameter whose density is wanted. The contour integral of such a term is that of the t-ratio (tnode_values!) with two changes, both from the same integration by parts in v. First, the constant A of X need not be the shift a of Mt (the t-ratio and the coefficient statistic have A = a; the line U - aV <= b has X(v) = a v^2 + a + b): the term P(R <= A under the tilt) is split at R = 0, (1 - e^{-As})/s on G+ and -1/s on G- for A > 0, -e^{-As}/s on G- for A < 0, -1/s on G- for A = 0. Second, with a finite vmax the v-pieces end at vmax and the boundary term -e^{-t vmax^2} P(R <= X(vmax) under the tilt) is added (bnd = true). The density kernel is 2 v dX/dparameter = 2 (dc0 v^3 + dq v^2 + dA v); the term of a moving vmax is left out, which is right when the terms of the event have the same X(vmax) and weights that sum to zero there (as the two parabolas of ADFmax, where bnd = false drops their boundary terms, which cancel exactly).

DFLimit.DFDet.contour_eval — Function
contour_eval(CP, xs; c0 = 0, n, ntail, alpha = 0.5, tol = 1e-17, warn = true) -> (F, f, nodes, (F = eF, f = ef))

The distribution function F(x) = P(tau <= x) and the density f(x) of tau = (U - c0 V)/sqrt(V) at the points xs by the contour integral: the trapezoidal rule in u >= 0 on the hyperbola CP (which carries the design and its start), F = (h/pi) sum' Im{IF(tk) t'(uk)/tk} and f likewise, the outer nodes processed in chunks of 32 until a chunk whose terms all stay below tol. vpow = 3 replaces the density kernel 2 v^2 by 2 v^3: at x = 0 the derivative of F in c0, the density of the coefficient statistic (coef_pdf). n and ntail are the nodes per panel and on the tails of the rays: 24 and 40, with a fixed start 48 and 64 (the essential singularities). The fourth output holds, for each x, the estimates eF and ef of the rounding error: eps times the sums over all nodes (inner and outer, with the weights) of (1 + |log Mt|) |term|, the terms with their kernels (tnode_inner!). A warning when the largest of them exceeds WARNTOL[] = 1e-4 (the transform is then large on the paths and the sums cancel), when a value is not finite, or when the outer contour ends (at |t - tau| = 1e5) with terms above 1e-10. Measured against DFLimit with a fixed start, the actual error is 0.005 to 0.03 times the estimate where rounding dominates (badly placed paths) and of the order of the estimate or below elsewhere (`scripts/checkfixedfar.jl). The estimate covers rounding and cancellation, not the discretization error, which the panel rules control (nsplit, the grading toward roots and origin). On the vertical line the parts of the kernels at the root of the parabola, which carry e^{-t v^2}, go to Filon's rule (filonrootsx,contoursumfilon`; filon = false: the line's Gauss-Legendre rule for them as well, as before). contoureval(P, CP, xs; ...) is the same (P is not used).
